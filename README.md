# Real-Estate-Investment-Advisor

An end-to-end Machine Learning application designed to assist investors in evaluating real estate property profitability and future value.

## 🚀 Overview
This project provides a data-driven approach to real estate decision-making. By analyzing key property features (location, size, amenities, etc.), the system:
1. **Classifies** whether a property is a "Good Investment."
2. **Forecasts** the estimated price of the property after 5 years using regression analysis.

## 🛠 Tech Stack
- **Languages:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn, XGBoost/RandomForest
- **Deployment:** Streamlit
- **Tracking:** MLflow

## 📊 Key Features
- **Data Preprocessing:** Handled missing values, outliers, and categorical encoding.
- **Exploratory Data Analysis (EDA):** Conducted 20+ analyses covering price trends, location impact, and amenity correlation.
- **Machine Learning Models:** Trained classification and regression models for predictive insights.
- **Interactive UI:** A user-friendly Streamlit interface for real-time property assessment.
